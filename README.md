# AdrenalTumorDetectorClassifier
НИР "Диагностика заболеваний (образований) надпочечников с помощью ИИ"

### branch - ```backend```

Векта подготовки моделей для встраивания в backend

Cтруктура:
```commandline
model_files/                            # Папка для моделей
test_data/                              # Папка для обрабатываемых данных
nnmodel/
    ├── __init__.py                     
    ├── models/                         # Папка с классами моделей
    │   ├── BaseNNModel.py              # Базовый класс для моделей 
    │   ├── SegmentationModel.py        # Модель сегментатора
    │   └── ClassificationModel.py      # Модель классификатора
    ├── utils/                          # Папка с дополнительными инструментами
    │   ├── save.py                     # Функции для сохранения видео
    │   └── separate.py                 # Функция разделяющая видео с несколькими образованиями на отдельные видео с одним образованием    
    ├── CTModel.py                      # Общая модель нейросети КТ
    └── settings.py                     # Настройки загрузки моделей (путей до моделей)
tests/
    ├── __init__.py
    ├── test_main.py                    # Юнит-тест основных функций и атрибутов КТ модели 
    ├── test_save.py                    # Юнит-тест функции сохранения видео детекции и сегментации
    └── test_separate.py                # Юнит-тест функции разделения образований
main.py                                 # Пример использования модели и вывод атрибутов модели
```

## Проведение юнит-тестов

```
0. Запросите и загрузите модели в папку model_files/ и проверьте названия моделей в settings
1. Создать папку с файлами для теста в корне проекта 
2.1. ИЛИ Загрузить в папку видео КТ снимка в видео форматах (MP4, AVI, MKV, MOV, MPEG, WMV)
2.2. ИЛИ Загрузить в папку видео КТ снимка в видео формате массива numpy (NPY)
2.3. ИЛИ Загрузить в папку архив (ZIP) с кадрами формата dicom ([без разширения], DICOM, DCM)
2.4. ИЛИ Передать путь до папки с кадрами формата dicom ([без разширения], DICOM, DCM)
3. В тесте прописать путь до файла для проведения анализа
```
